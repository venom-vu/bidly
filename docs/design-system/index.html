5 · Kiến Trúc Popup / Modal 3 Lớp (Modal Architecture)

Đăng ký Trải Nghiệm Bidly Preconstruction CRM

Điền thông tin doanh nghiệp để chuyên viên giải pháp thiết lập môi trường dữ liệu mẫu phù hợp với loại hình tổng thầu của bạn.

Cấu trúc 3 lớp: Header (Cố định) + Body cuộn an toàn (`max-h-[calc(100dvh-8rem)]`, `overflow-y-auto`, `min-h-0`) + Footer (Cố định).
